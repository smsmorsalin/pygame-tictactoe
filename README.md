A fully functional **Tic Tac Toe game built using Pygame** in Python.  
This project features a graphical interface, sound effects, background music, and a two-player local gameplay system.

---

## 🎮 Features

- 🎨 Clean graphical UI built with **Pygame**
- 👥 Two-player local mode
- 🖱 Mouse click controls
- 🏆 Win detection (horizontal, vertical, diagonal)
- 🤝 Draw detection
- 🔊 Sound effects (click, win, menu)
- 🎵 Background music
- ✍ Player name input system

## 🚀 Installation

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/smsmorsalin/pygame-tictactoe.git
```
```
cd pygame-tictactoe
```
## 2️⃣ Install Dependencies

Make sure **Python 3.8+** is installed.

Install Pygame manually:

```bash
pip install pygame
```
Or use the requirement file:
```bash
pip install -r requirement.text
```
▶️ **Run the Game**
```bash
python tictactoe.py
```
The game window will open and you can start playing 🎉
